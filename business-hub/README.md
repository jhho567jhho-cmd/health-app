# 📊 מרכז ניהול העסק

אפליקציה אחת (קובץ `index.html`) לניהול העסק הדיגיטלי במקום אחד:

- **דשבורד** - סיכום מהיר של לקוחות, משימות, תוכן, כספים והזמנות
- **לקוחות ולידים** - רשימת אנשי קשר וסטטוס
- **משימות** - רשימת לביצוע עם תאריכי יעד
- **לוח תוכן** - רעיונות ופוסטים לפי תאריך ופלטפורמה
- **כספים** - הכנסות והוצאות, רווח נקי
- **שיווק קישורים (אפיליאט)** - רישום מוצרים עם קישור שותפים (AliExpress, Amazon, Temu), חישוב עמלה משוערת לפי קליקים ומכירות, ונוסח גילוי נאות
- **מוצרים והזמנות** - קורסים, מוצרים דיגיטליים, שירותים והזמנות
- **עוזרי AI** - הנחיות מוכנות (כתיבת פוסטים, תשובות ללקוחות, מיילים ועוד) שמועתקות ללוח

## הפעלה

פתחו את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

## נתונים

הנתונים נשמרים ב-LocalStorage של הדפדפן. להעברה למכשיר אחר או לגיבוי, השתמשו ב"ייצוא גיבוי" ו"ייבוא גיבוי" בראש העמוד.

## הערות
