# 💪 אפליקציית בריאות וכושר

אפליקציה מובייל לעקיבה אחרי בריאות, כושר ותזונה עם עוזר AI וממשק עברי מלא.

## 🎯 תכונות

### 🤖 עוזר בריאות
- עוזר AI עם תשובות מהירות
- שאלות על משקל, בריאות, מתכונים ותרגילים
- תשובות מקצועיות ומותאמות

### 📸 תמונות
- צילום ישיר מהטלפון
- בחירה מגלריה
- הערות על כל תמונה
- הסטוריה מלאה

### 🍽️ תפריט יומי
- רישום מנות אכילה
- ספירת קלוריות
- קטגוריות: בשר, דגים, ירקות, פרות, קרבוהידרטים

### ⚖️ עקיבה משקל
- רישום משקל יומי
- סטטיסטיקות (משקל אחרון + ממוצע)
- הסטוריה משקלים

### ✅ משימות בריאות
- יצירת משימות יומיות
- סימון משימות כהשלם
- עקיבה התקדמות

### 💡 טיפים בריאות
- טיפים אקראיים יומיים
- עצות לתזונה וכושר
- המוטיבציה יומית

## 🛠️ טכנולוגיה

- **HTML5** - מבנה האפליקציה
- **CSS3** - עיצוב יפה וריאקטיבי
- **Vanilla JavaScript** - לוגיקה ויתר פונקציונליות
- **LocalStorage** - שמירת נתונים במקומי
- **RTL Support** - תמיכה מלאה בעברית

## 🚀 התחלה

פשוט פתח את הקובץ `index.html` בדפדפן:

```bash
open index.html
# או
# הקלק על הקובץ בישירות
```

## 💾 נתונים

כל הנתונים נשמרים בـ LocalStorage של הדפדפן:
- תמונות (כ-Base64)
- משקלים
- משימות
- טיפים שנוצרו

## 📱 התאמה לטלפון

- טאבלט: מספיק מוצל
- מחשב: עובד בחלונית
