# דרופשיפינג משותף

אפליקציה משותפת לחיים ולדבורה לניהול מוצרים (לפי מקורות כמו AliExpress ו-eBay) והזמנות.
כל הנתונים נשמרים ב-Supabase, כך שאתם רואים את אותו מידע מכל מכשיר.

## מה יש היום

- **מוצרים**: רשימה של מוצרים שבוחנים, עם מחיר ספק, מחיר מכירה, עמלת פלטפורמה וסטטוס.
  הרווח הנקי והאחוז מחושבים אוטומטית.
- **הזמנות**: הזמנות שנכנסו, עם מספר מעקב, מספר הזמנה אצל הספק וסטטוס משלוח.
  מוצג סיכום של הכנסות ורווח נקי.
- כניסה עם אימייל וסיסמה, רק לשני המשתמשים שתיצרו.

כל הסכומים מוזנים **בשקלים (₪)**. מחיר ספק ב-AliExpress נמצא בדולרים, אז ממירים לפני ההזנה.

## הקמה (פעם אחת)

1. **יוצרים פרויקט ב-Supabase** בכתובת https://supabase.com (חינמי).
2. **מריצים את הסכמה**: בתפריט הצד נכנסים ל-*SQL Editor* → *New query*,
   מדביקים את התוכן של `supabase/schema.sql` ולוחצים *Run*.
3. **סוגרים הרשמה חיצונית**: *Authentication* → *Sign In / Providers* → מכבים
   *Allow new users to sign up*. כך אף אחד אחר לא יכול להירשם.
4. **יוצרים שני משתמשים**: *Authentication* → *Users* → *Add user* → *Create new user*,
   אחד לחיים ואחד לדבורה (עם אימייל וסיסמה).
5. **מעתיקים את המפתחות**: *Project Settings* → *API*. לוקחים את *Project URL*
   ואת ה-*anon public* key.
6. **מגדירים את האפליקציה**:
   ```bash
   cp .env.example .env.local
   # ממלאים בקובץ את VITE_SUPABASE_URL ו-VITE_SUPABASE_ANON_KEY
   npm install
   npm run dev
   ```
   ואז פותחים את הכתובת שמופיעה (בדרך כלל http://localhost:5173).

## פקודות

- `npm run dev` - הרצה מקומית לפיתוח
- `npm test` - הרצת הבדיקות (חישובי רווח)
- `npm run build` - בנייה לפרודקשן (בתיקיית `dist/`)

## מה הלאה

- העלאה לאינטרנט (Vercel או Netlify) כדי שתוכלו להיכנס מהטלפון
- שדה מטבע והמרה אוטומטית מדולר
- מעקב משלוחים ותזכורות
- רשימת משימות והערות משותפות
- אוטומציות (בוטים) לאיתור מוצרים: נעשה זאת רק אחרי שנבדוק את תנאי השימוש של כל אתר
